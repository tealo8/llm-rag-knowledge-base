# 幻觉抑制、安全策略与失败降级

## 会话分享边界

分享默认只读、默认 72 小时过期；服务端只保存随机 token 的摘要，密码以 PBKDF2 哈希保存。访问密码通过 POST 请求体提交，响应禁止缓存且设置 `Referrer-Policy: no-referrer`。分享接口不接受知识库查询参数，也不允许匿名追加问题。`continue` 模式目前只保存为授权模型字段，真正开放继续问答前必须接入登录态、短期令牌和完整 ACL。

## 幻觉抑制

1. **相似度和词项阈值**：向量分数低于管理员配置阈值时过滤；BM25 候选还要满足查询词项重合。
2. **严格知识库模式**：无授权证据时直接回复“知识库未查询到相关信息”，不把空上下文交给模型自由作答。
3. **证据隔离 Prompt**：检索片段以不可信 `<source>` 数据注入，禁止片段中的内容改写系统规则。
4. **引用约束**：要求事实段落标注 `[1]` 等来源编号，校验编号范围、段落覆盖、词项支持和拉丁实体。
5. **抽取式降级**：模型响应超时、引用不支持或格式异常时，从检索片段抽取带引用句子。
6. **反馈闭环**：保存点赞/点踩和问答样本，用于评估集扩充；启发式校验不能证明自然语言蕴含关系。

## 安全防护

| 控制 | 当前策略 | 残余风险 |
| --- | --- | --- |
| 身份 | JWT，账号启用状态校验 | 未接企业 SSO/OIDC、MFA、令牌撤销 |
| 租户/权限 | 组织、知识库、文档 ACL 在召回前执行 | PGVector 是逻辑隔离，不是独立数据库 |
| Prompt 注入 | 拦截常见“忽略指令/泄露 prompt”模式，文档内容视为不可信 | 新型、多语言和编码绕过 |
| 文件上传 | 扩展名白名单、大小限制、PDF/Office 文件头 | 未接杀毒、解析沙箱、压缩炸弹防护 |
| 接口限流 | 进程内滑动窗口，超限返回 429 | 多副本必须使用 Redis/网关限流 |
| IP 策略 | CORS 可配置；公开演示应使用反向代理 IP 白名单 | CORS 不是网络访问控制，生产需 WAF/网关 |
| 审计 | 上传、删除、问答、权限和反馈写入审计；查询默认只存 hash/长度 | 未实现不可变审计和 SIEM |
| 输出 | 可配置敏感词替换、引用支持校验 | 不是语义 DLP 或人工审核 |

## 失败降级矩阵

| 故障 | 用户可见结果 | 服务端处理 | 数据安全原则 |
| --- | --- | --- | --- |
| 文档解析失败 | 文档为“解析失败”，展示错误原因，支持重试 | 记录失败状态和日志，不写入空索引 | 不把坏数据标为成功 |
| 扫描图片 PDF | 提示需要 OCR | 不创建可检索空内容 | 不编造 OCR 结果 |
| Embedding 宕机/超时 | 显示“全文检索降级” | 重试后切 BM25；指标记录原因 | 不因模型失败放开 ACL |
| LLM 宕机/超时 | 返回带引用的抽取式降级或友好超时 | 重试、超时、错误脱敏 | 不向前端返回堆栈 |
| PGVector/Chroma 异常 | 查询降级或写入失败提示 | 可降级 BM25；写入文档置失败 | ACL/鉴权失败必须 fail closed |
| Celery/Redis 异常 | 文档停留 queued 或 failed | 晚确认、worker 丢失重投、最多 3 次重试，耗尽写死信 | 不假装已索引 |
| 大文件/OOM | 上传限制或任务失败提示 | 分片传输、任务超时、失败可重试 | 限制单文件和并发资源 |
| 数据库锁/损坏 | 友好服务错误 | SQLite WAL、备份恢复、管理员重建索引 | 不降级为开放访问 |

## 运营检查

- 监控 `/metrics` 的请求量、429、模型耗时、Embedding 错误和检索降级比例。
- 定期执行 `scripts/backup.py`，并在隔离环境用 `scripts/restore.py` 做恢复演练。
- 生产 Compose 需要补 Prometheus/Alertmanager 规则、Redis 高可用、死信告警、对象存储、数据库加密和漏洞扫描。
- 对高风险回答要求用户点击原文核对；引用可打开不等于结论一定正确。
