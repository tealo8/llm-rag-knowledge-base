# 资源与推理成本测算

## 口径

下表区分已核实事实、部署假设和待填价格。私有化没有第三方 token 账单，但硬件、电力、存储、备份和运维仍然产生成本。不要把“API 费用为零”写成“总成本为零”。

## 已核实本机资源

| 项目 | 数值 | 证据 |
| --- | ---: | --- |
| `qwen2.5:7b` 模型文件 | 4,683,087,332 bytes（约 4.36 GiB） | Ollama `/api/tags` |
| `qwen3-embedding:0.6b` 模型文件 | 639,150,858 bytes（约 0.60 GiB） | Ollama `/api/tags` |

| Embedding 输出 | 1024 维 | Ollama `/api/embed` |
| 建议最低内存 | 16 GiB | 单用户 CPU 演示经验下限，不是 SLA |

## 本地部署

| 资源 | 建议配置 | 成本项 |
| --- | --- | --- |
| CPU | 8 核以上更适合问答；4 核仅低并发试运行 | 购机/折旧、电费 |
| 内存 | 16 GiB 起步；长上下文和并发需要更多 | 购机/升级 |
| GPU | 可选；显存需按量化模型和并发压测 | GPU 折旧、电费 |
| 磁盘 | 模型约 4.96 GiB，另加原文、索引、WAL、备份 | SSD、备份空间 |
| 软件 | Ollama、FastAPI、SQLite/Chroma；生产可用 PGVector/Celery | 运维时间 |

本地月度成本公式：

```text
电费 = 平均增量功率(W) / 1000 × 运行小时/月 × 电价(元/kWh)
硬件折旧 = 可分摊设备价格 × 本服务占比 / 预计使用月数
存储与备份 = 原文 + 向量 + 日志 + 备份副本的实际占用 × 单价
月总成本 = 电费 + 折旧 + 存储/备份 + 运维 + 监控/安全
```

## 云服务器部署

低并发试运行可以从 4 vCPU / 16 GiB 内存起步，配合持久化 SSD、PGVector、Redis 和 Ollama；这不是生产容量结论。GPU 云实例应根据实测 tokens/s、并发和上下文长度选型。

```text
云主机月费 = 实例小时单价 × 运行小时
云盘月费 = (原文 + PGVector + 备份) GB × 云盘单价
公网/跨区流量 = 实际出站 GB × 流量单价
云总成本 = 主机 + 云盘 + 数据库/对象存储 + 流量 + 备份 + 监控
```

具体人民币价格必须引用部署区域、供应商、计费模式和当日官方报价。本仓库没有这些输入，不编造固定月费。

## Embedding 与 LLM 推理

本项目默认调用本地 Ollama：外部 token 费用为 0，但有 CPU/GPU 时间和电力成本。请求会记录 prompt/completion token、模型耗时和重试次数，可用于容量和机会成本分析。

如果切换远程服务：

```text
Embedding 月费 = 输入 tokens × embedding 单价 / 1,000,000
LLM 月费 = (输入 tokens × 输入单价 + 输出 tokens × 输出单价) / 1,000,000
总推理费 = Embedding 月费 + LLM 月费 + 重试/缓存/网络费用
```

远程价格必须绑定具体供应商、模型版本、区域、输入/输出 token 和缓存策略；价格变化后应更新测算，不把示例价格写成长期事实。

## 容易漏算

OCR、杀毒扫描、解析沙箱、数据库备份、跨区复制、模型更新、失败重试、日志留存、SSO/MFA、漏洞修复、人工标注、容量压测和安全响应都应单独列项。
