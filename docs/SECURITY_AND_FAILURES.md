# 幻觉、安全与失败场景

## 已实现的控制

| 风险或失败 | 当前处理 | 可观察结果 |
| --- | --- | --- |
| 跨租户/跨库/越组检索 | 组织、知识库和文档 ACL 在候选前执行；外部向量查询还过滤授权文档 ID | 无权资源返回 404；测试覆盖跨租户、跨库和指定用户 |
| 无相关证据 | 词项重合 + 向量绝对阈值 | 无引用并明确拒答 |
| 模型伪造引用编号 | 只允许 `[1..N]` | 校验失败后切换抽取式答案 |
| 明显无支持的引用 | 回答词项与引用片段做最小支持校验，并要求拉丁实体在来源中出现 | `generation_mode=extractive_degraded` |
| 文档内提示注入 | 资料用 `<source>` 隔离，系统提示将其定义为不可信数据 | 仍需红队评估，不能保证完全免疫 |
| 用户输入提示注入 | 可配置模式过滤常见的系统指令覆盖、提示词泄漏和忽略前文请求 | 返回 400；启发式规则会有漏报和误报 |
| 敏感输出 | 管理员维护敏感词列表，回答返回前替换命中项 | 记录过滤数量；不等同于语义级 DLP |
| Embedding 超时/断网 | 最多 2 次重试，指数退避 | `retrieval_mode=lexical_degraded` 和原因 |
| 生成超时/坏响应 | 最多 2 次重试；抽取式降级 | 返回可用答案并明确显示降级 |
| 模型版本切换 | 片段保存模型名/维度，只检索当前版本 | 状态页显示过期数量；管理员重建 |
| 损坏/空/超大文件 | 类型、大小、PDF/Office 文件头、解析和空文本校验 | 文档标为 failed，API 返回明确错误 |
| 扫描图片 PDF | 没有可提取文本时识别为 OCR 缺失 | 文档标为 failed，提示安装 OCR；不会把空内容入库 |
| 外部向量库故障 | 写入失败中止索引；查询失败保留 BM25 并标记降级 | 返回友好错误或 `lexical_degraded`，不暴露堆栈 |
| 原始查询含敏感信息 | 新事件默认不保存原文，只存 SHA-256 和长度；API 同时屏蔽历史原文 | 管理员审计页不显示原始问题 |
| 弱生产配置 | 启动时校验演示模式和 JWT 密钥 | 配置不合格则拒绝启动 |

## 幻觉边界

引用合法、能打开和词项/实体重合都不能证明“引用蕴含结论”。模型仍可能误读否定词、数字、日期、版本冲突或表格；如果恶意文档本身声称一个虚假事实，输出原样复述时也可能通过支持校验。当前提示词、低温度、拒答、引用验证和抽取式降级降低风险，但没有消除幻觉。高风险业务应要求用户打开原文，并增加文档来源可信度、审批状态、人工标注的事实一致性评估或独立判别流程。

当前支持技术版本组和当前版本切换，但没有业务生效日期、废止日期和冲突优先级模型。如果不同文件的制度互相冲突，系统可能同时引用却不能自动判断哪份有效。这是企业知识库常被忽略的治理变量。

升级前已经写入数据库的历史查询不会被自动删除，只在默认 API 输出中屏蔽。若这些记录包含真实敏感信息，应按企业保留策略执行一次性清理或迁移；自动删除会破坏审计证据，因此项目不替管理员做该决定。

## 尚未完成的生产控制

- 企业 OIDC/SAML SSO、MFA、账号生命周期和短期令牌撤销；
- 恶意软件扫描、压缩炸弹防护、OCR 和解析沙箱；
- Celery 任务队列已提供超时、重试和 worker 丢失重投；仍需补任务幂等键、死信告警和服务端断点恢复；
- API 限流已提供进程内滑动窗口；多副本部署必须换 Redis/网关限流，并补并发隔离、熔断器、资源配额和成本预算；
- 数据库与原文加密、备份、恢复演练、保留/删除策略；
- 不可变审计、SIEM、链路追踪和值班告警；Prometheus 文本指标已提供，但尚未接入采集和告警规则；
- CSRF/CSP/安全响应头、外部渗透测试和依赖漏洞门禁；
- Chroma/PGVector 的容量、并发、备份恢复、删除一致性和故障注入实测；
- SQLite 元数据迁移到可多副本使用的关系数据库。

## 失败场景决策

Embedding 故障时保留 BM25，可用性优先但召回能力下降；界面必须显示“全文检索降级”。生成故障时返回由检索片段抽取的带引用文本，可用性优先但表达质量下降。数据库、鉴权或 ACL 失败时不降级为开放访问，应直接失败关闭。生产环境中连续模型故障还需要熔断和告警；当前只有请求内重试，没有跨请求熔断器。
